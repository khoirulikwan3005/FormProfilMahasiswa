
# Form Profil Mahasiswa

Aplikasi Android sederhana untuk mengisi dan menampilkan data profil mahasiswa. Proyek ini dibuat menggunakan Kotlin dan Jetpack Compose sebagai penerapan materi pengembangan antarmuka Android.

## Fitur Aplikasi

- Input nama lengkap mahasiswa.
- Input Nomor Induk Mahasiswa (NIM).
- Pilihan program studi melalui dropdown.
- Pilihan semester melalui dropdown.
- Menampilkan hasil profil pada halaman terpisah.
- Tombol untuk kembali ke formulir dan mengedit data.

## Teknologi yang Digunakan

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

## Konsep yang Diterapkan

### 1. State

State digunakan untuk menyimpan data nama, NIM, program studi, semester, serta kondisi halaman yang sedang ditampilkan.

### 2. Event

Event digunakan untuk menangani interaksi pengguna, seperti mengetik data, memilih program studi dan semester, serta menekan tombol untuk menampilkan profil.

### 3. Recomposition

Recomposition memungkinkan antarmuka diperbarui ketika nilai state berubah. Data yang dimasukkan pada formulir kemudian ditampilkan pada halaman profil.

## Cara Menjalankan Aplikasi

1. Buka proyek melalui Android Studio.
2. Tunggu proses Gradle Sync selesai.
3. Hubungkan perangkat Android atau gunakan emulator.
4. Jalankan aplikasi menggunakan tombol Run.
